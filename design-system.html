House rules The ones that bite

Before you change a value

Don't rescale rem values again.Every rem in the codebase was mechanically rescaled by 16/12 when the root moved to 75%, specifically so nothing changed size. Only new values should use the scale table directly.
Map to the nearest step, don't invent one.Not every step needs to appear in a given component — skip the ones that don't carry a distinct role.
Check contrast before adding a colour.4.5:1 for text, 3:1 for large text, UI components and borders. --line is divider-strength only (~1.3:1); use --line-strong where a border is a control's only visible boundary.
Accent and secondary need inverse variants.On inverted backgrounds use --accent-on-inv and --secondary-on-inv — the standard ones fail contrast there in Carbon and Petrol.
Three breakpoints, no more.Reach for clamp() before adding a fourth. Queries are for structural changes a fluid value can't express — a hamburger, a column count, a reorder.
Gate new motion.Anything animated respects prefers-reduced-motion, including JS-driven scroll.
