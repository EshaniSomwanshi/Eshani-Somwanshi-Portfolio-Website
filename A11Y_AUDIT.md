# Accessibility Audit — 2026-09-06

Scope: Full frontend codebase (`frontend/src/`), both routes — `/` (`App.js`, one-page portfolio) and `/work/:slug` (`CaseStudyPage.js`). All components actually rendered by these two routes were reviewed: `primitives.js`, `AvatarHero.jsx`, `InteractiveAvatar.jsx`, `Preloader.jsx`, `ReadMode.jsx`, `BeforeAfter.jsx`, `MacBookScroll.jsx`, `Assemble.jsx`, `RotateCard.jsx`, `caseStudies.js`, `index.js`, `public/index.html`, and the CSS design tokens in `App.css` (all three themes: paper/carbon/petrol).

**Out of scope (dead code, confirmed unused by grep — not imported from either route):** the entire shadcn `components/ui/*.jsx` kit except `AvatarHero.jsx`/`InteractiveAvatar.jsx` (accordion, dialog, tabs, carousel, etc. — ~45 files), plus `components/devices/DeviceShowcase.jsx`, `ContactDevice.jsx`, and `PhoneFrame.jsx` (only referenced by the unused `DeviceShowcase`). Tools: **Static code review only** — Lighthouse, axe, WAVE, and a live VoiceOver/keyboard pass were not run this session (no working browser automation available to me in this environment). Contrast ratios below were computed programmatically from the actual CSS custom-property values using the WCAG relative-luminance formula, not eyeballed. ### P2 items (log only, not yet fixed)
- `CaseStudyPage.js:73` (`<b>ES/</b>`) and the (currently unused, dead-selector) `.wordmark b` rule in `App.css:274` use `<b>` where `<strong>` would be more semantically correct — very minor, no real user impact since neither conveys actual emphasis of meaning.
- `BeforeAfter.jsx:105` bakes the current percentage into `aria-label` (`aria-label={\`Comparison slider, ${pct}% ${beforeLabel}\`}`) alongside `aria-valuenow` — works, but `aria-valuetext` is the more idiomatic ARIA-slider way to expose a human-readable value without redundancy.
- Desktop `.theme-dot` buttons (`App.css:352`) are 32px tall — passes the AA 24×24px minimum comfortably, but short of the AAA 44×44px recommendation (2.5.5). The mobile variant already hits 44px (`App.css:442`).
- 1.4.6 Contrast (Enhanced, AAA / 7:1) was not pursued as a blanket target — most body-text pairs already clear 5–18:1 (see the contrast table computed during this audit), but no systematic 7:1 pass was done.
- 3.1.4 Abbreviations — HCI, UX, MVP, B2B, SaaS, NDA, MS appear in body copy without expansion on first use or `<abbr title="...">`.
